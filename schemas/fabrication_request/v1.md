# CircuitC fabrication request v1

## Status and authority

Version 1 is the deterministic pre-execution contract for exporting one exact
generated PCB through KiCad 10.0.5. It is derived from valid Design IR, one
authenticated Layer-3 product bundle and selected variant, one exact authored
manufacturability analysis/assertion, and exact compiler-emitted board bytes.
It is not caller policy, host output, or release evidence.

## Encoding and path

The artifact is compact canonical UTF-8 JSON followed by exactly one LF. Field
order is the order below. Unknown, missing, duplicate, reordered,
pretty-printed, trailing, or otherwise non-canonical fields or bytes are
invalid. The complete request is at most 67,108,864 bytes.

`fabrication_identity_sha256` is defined by
[ADR-0011](../../docs/adr/0011-deterministic-kicad-fabrication-evidence.md).
The only request path is
`fabrication/<fabrication_identity_sha256>/request.json`.

## Root object

The root has exactly these fields in this order:

| Field | Type | Contract |
| --- | --- | --- |
| `schema_name` | string | Exactly `circuitc.fabrication_request`. |
| `schema_version` | u32 | Exactly `1`. |
| `design_name` | string | Exact safe Design artifact stem. |
| `analysis_path` | string | Exact authored KiCad-10 manufacturability analysis path. |
| `assertion_path` | string | Exact authored `fabrication_inventory_complete` assertion path within that analysis. |
| `variant_path` | string | Exact selected variant path. |
| `variant_identity_sha256` | string | Recomputed Layer-3 variant identity. |
| `product_input_sha256` | string | Recomputed Layer-3 common product-input digest. |
| `product_resolution_sha256` | string | SHA-256 of exact canonical resolution bytes including LF. |
| `placement_sha256` | string | SHA-256 of exact canonical placement bytes including LF. |
| `catalog_evaluated_on` | string | Authenticated authored `YYYY-MM-DD` evaluation date used for native date normalization. |
| `kicad_pcb` | object | Exact `path`, `sha256` binding for `<design_name>.kicad_pcb`. |
| `expected_adapter` | string | Exactly `kicad`. |
| `expected_major` | u32 | Exactly `10`. |
| `expected_version` | string | Exactly `10.0.5`. |
| `fabrication_identity_sha256` | string | Recomputed identity from the exact preimage. |
| `export_profile` | object | Exact fixed profile below. |
| `outputs` | array | Exact ordered 13-entry role/path-suffix inventory. |

Every SHA-256 is 64 lowercase hexadecimal characters. Artifact paths are
canonical portable relative paths. Output suffixes are exactly those listed in
ADR-0011 and are unique.

## Export profile

`export_profile` has exactly `gerber`, `drill`, `position`, and `resources`.

`gerber` has `format:"x2"`, `precision:6`, `net_attributes:true`,
`protel_extensions:false`, `origin:"page"`, `board_plot_params:false`, and
`layers`. `layers` contains exactly the nine ID/name/native-function/job-
function/polarity/path records in ADR-0011, strictly sorted by numeric layer
ID.

`drill` has exactly `format:"excellon"`, `origin:"absolute"`, `units:"mm"`,
`zero_format:"decimal"`, `oval_format:"alternate"`, `mirror_y:false`,
`minimal_header:false`, `separate_plated:true`, `generate_map:false`,
`generate_report:false`, and `generate_tenting:false`.

`position` has exactly `format:"csv"`, `units:"mm"`, `side:"both"`,
`origin:"page"`, `bottom_negate_x:false`, `smd_only:false`,
`exclude_through_hole:false`, `exclude_dnp:false`, and required nullable
`variant:null`.

`resources` has exactly `timeout_ms:120000`, `stdout_bytes:1048576`,
`stderr_bytes:1048576`, `file_bytes:67108864`,
`aggregate_bytes:268435456`, `primary_rows:10000`, and `diagnostics:256`.

No arbitrary executable arguments, filesystem paths, current time, user
configuration, or directory-discovered file enter the request.

## Verification and failure

The request compiler revalidates the selected analysis/assertion and strictly
verifies the complete Layer-3 bundle against Design and exact catalog bytes.
For a static Design it independently recompiles and exactly compares all
compiler artifacts. A Design with simulation analyses or routing requests must
provide opaque checked compiler artifacts. Simulation-only board lowering is
independently reproduced without executing the simulator. Routed board
lowering is deterministically replayed from the current Design and retained
authenticated route result, including request, result, selected candidate,
projection, and complete static-artifact equality. The later release layer
still binds the complete simulation/routing evidence chain, but Layer 4 does
not defer board authentication. The request compiler recomputes every digest,
profile field, descriptor, identity, and canonical byte. Any stale input,
unsupported adapter/version, unsafe path, size overflow, or mismatch returns a
stable fabrication diagnostic and no request.
