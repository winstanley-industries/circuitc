# CircuitC board-analysis request schema v1

`circuitc.board_analysis_request` v1 is the strict pre-execution contract for
the first capability-declared KiCad manufacturability adapter. It is compact
canonical JSON plus one final LF, at most 67,108,864 bytes, with the exact root
field order below. Unknown, missing, duplicated, reordered, or differently
typed fields are invalid.

| Field | Type | Meaning |
| --- | --- | --- |
| `schema_name` | string | Exactly `circuitc.board_analysis_request`. |
| `schema_version` | integer | Exactly `1`. |
| `design_name` | string | Exact current Design name. |
| `analysis_path` | string | Exact authored manufacturability analysis path. |
| `adapter` | string | Exactly `kicad`. |
| `expected_major` | integer | Exactly `10`. |
| `expected_version` | string | Exactly `10.0.5`. |
| `analysis_identity_sha256` | string | Domain-separated identity defined below. |
| `assertions` | array | Exact five ordered assertion descriptors. |
| `kicad_schematic` | artifact binding | Exact generated schematic. |
| `kicad_pcb` | artifact binding | Exact generated PCB. |
| `kicad_identity_map` | artifact binding | Exact frontend identity-map bytes. |
| `expected_sheets` | array | Exact ordered schematic sheet inventory. |
| `project_support` | array | Exact ordered KiCad project support artifact bindings. |
| `fabrication_request` | artifact binding | Exact authenticated Layer-4 request. |
| `fabrication_manifest` | artifact binding | Exact authenticated Layer-4 manifest. |
| `policy` | object | Fixed KiCad finding policy. |
| `resources` | object | Fixed resource policy. |
| `outputs` | array | Exact host output descriptors. |

An artifact binding contains exactly `path`, `byte_length`, and lowercase
`sha256`. Paths are canonical portable relative paths. An assertion descriptor
contains exactly `assertion_path` and `capability`. Assertions are ordered
`erc_clean`, `drc_clean`, `unconnected_clean`, `schematic_parity_clean`, and
`fabrication_inventory_complete`; each path is the exact Design-owned path for
that capability.

Each `expected_sheets` entry contains exactly `path` and `uuid_path`, in that
field order. The array is derived deterministically from the authenticated
schematic and KiCad identity inventory. The current backend emits exactly the
root `{ "path": "/", "uuid_path": "/<design.schematic UUID>" }` entry.
Completed ERC evidence must reproduce the exact array order and values;
missing, duplicate, reordered, or substituted sheets are invalid evidence.

`project_support` is the complete compiler-emitted host support set beyond the
separately bound schematic, PCB, and identity map. It contains the
`<design_name>.kicad_pro` project, every emitted KiCad library file at its
canonical relative path, `sym-lib-table`, and `fp-lib-table`. Entries are
artifact bindings sorted by canonical path. Paths must be unique, every entry
is subject to the per-file limit, and the complete support inventory is subject
to the aggregate input limit. Missing, additional, duplicate, reordered,
renamed, or byte-mutated support entries change or invalidate the request.

`policy` contains exactly `included_severities`, `erc_ignored_checks`,
`drc_ignored_checks`, and `drc_library_warning`, with the values fixed by
ADR-0012. `resources` contains exactly `timeout_ms`, `stdout_bytes`,
`stderr_bytes`, `file_bytes`, `aggregate_bytes`, `primary_rows`, and
`diagnostics`, set respectively to 120000, 1048576, 1048576, 67108864,
268435456, 10000, and 256.

`outputs` is exactly:

```json
[{"role":"erc","path":"erc.normalized.json"},{"role":"drc","path":"drc.normalized.json"},{"role":"receipt","path":"receipt.json"}]
```

`analysis_identity_sha256` is lowercase SHA-256 over ASCII
`CIRCUITC-BOARD-ANALYSIS-IDENTITY-V1`, one NUL byte, and compact canonical JSON
without final LF containing, in order, every request field from `design_name`
through `outputs` except `analysis_identity_sha256`. Schema name and version
are not in the preimage.

The output root is `board-analysis/<analysis_identity_sha256>/`; request,
result, and report paths are exact children of that root.
