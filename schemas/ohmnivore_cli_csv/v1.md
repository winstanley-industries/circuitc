# Ohmnivore CLI CSV adapter contract v1

## Status and authority

This document pins the ephemeral raw process grammar accepted from Ohmnivore
`0.1.0` at source revision
`c2189a651d4879211019e109b2136dee836a5c5d`. It is an adapter contract, not a
published CircuitC artifact schema. Raw CSV, stderr, process paths, and timing
are never authoritative and never enter normalized evidence.

The process is invoked once per already-validated one-analysis netlist with
`--cpu`. Version output must be exactly `ohmnivore 0.1.0` followed by one LF and
no stderr. Analysis output is unquoted UTF-8, comma-separated, LF-terminated,
contains no blank rows, whitespace padding, CR, NUL, or quote characters, and
must fit the configured byte and collection envelopes. Every numeric cell is a
complete finite Rust `f64` display spelling; CircuitC canonicalizes it to the
normalized-result number format and maps negative zero to positive zero.

Any nonzero exit, timeout, resource overflow, unexpected stderr, malformed or
partial CSV, unknown or incomplete identity inventory, non-finite value, wrong
axis, missing authenticated sample, or missing transient stop produces a
non-completed normalized result with stable `CC-SIM-PROCESS-*` diagnostics and
no partial samples or signals.

## DC operating point

The exact header is:

```text
Variable,Value
```

Every following row has exactly two fields and a unique first field of
`V(<backend-node>)` or `I(<backend-branch-device>)`. For the initial R/Vdc
subset, output must contain every emitted non-ground node and exactly every
voltage-source branch, with no ground row, resistor current, unknown identity,
case drift, omission, or duplicate. CircuitC synthesizes one scalar zero axis
sample and normalizes rows to net-voltage and branch-current signals.

## Linear AC

The first header is exactly `Frequency`. Every remaining identity occupies one
adjacent exact pair:

```text
V(<node>)_mag,V(<node>)_phase_deg
I(<device>)_mag,I(<device>)_phase_deg
```

Pairs may not be orphaned, mixed, duplicated, unknown, or case-drifted. Every
data row has the exact header width. CircuitC recomputes the complete `LIN` grid
using the pinned order `start + ((stop - start) / (points - 1)) * index` and
requires identical row count and `f64` bits at every ordinal. It normalizes
magnitude and phase signals separately and requires the complete expected
node/voltage-source inventory.

## Transient

The first header is exactly lowercase `time`; each remaining header is one
unique `V(<node>)` or `I(<device>)`. Rows have exact width. CircuitC preserves
the actual adaptive emitted axis and requires finite strictly increasing times
inside the declared recording interval. It does not reconstruct, resample,
interpolate, epsilon-match, or choose a nearest nominal row.

The actual axis must contain the declared stop and every request-authenticated
assertion sample by exact lowered `f64` identity. Missing either after a zero
process exit is a deterministic execution failure with no accepted partial
payload. The complete expected node/voltage-source inventory is mandatory.

## Resource defaults

Handshake and analysis wall limits are 2 and 30 seconds within one five-minute
aggregate runner budget. Captured stdout and stderr are bounded independently
to 16 MiB and 64 KiB and drained concurrently.
The normalized structure is preflighted against the 64 MiB contract limit and
10,000-entry collection limits. Unix execution creates a separate process
group and applies CPU, file-size, descriptor, and core limits. Linux also
applies an 8 GiB address-space limit; Darwin has no claimed hard RSS ceiling.
The executable and provenance are fixed Bazel runfiles rather than caller
paths. The runner accepts only bounded regular files (2 GiB executable and
1 KiB sidecar) and hashes them once per runner under a 30-second identity
deadline. Handshake and
analysis directories are distinct; the analysis input is create-new/no-follow,
and cleanup is checked on every outcome. Process-group control bounds accidental
descendants of the trusted pinned backend, not a malicious executable that
deliberately escapes same-user process containment.
