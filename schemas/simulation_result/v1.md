# CircuitC normalized simulation result v1

## Status and authority

Version 1 is the deterministic normalized result produced from one simulation
request. Raw solver CSV and stderr are ephemeral and are not part of this
schema. The artifact uses strict canonical UTF-8 JSON with a final newline.
Unknown, missing, or duplicate fields are invalid.

All numbers are strings. The canonical encoding is Rust scientific formatting
with 17 fractional digits, for example `5.00000000000000000e0`. Negative zero
normalizes to positive zero. NaN, positive or negative infinity, overflow, and
any alternative spelling are invalid.

## Root object

| Field | Type | Contract |
| --- | --- | --- |
| `schema_name` | string | Exactly `circuitc.simulation_result`. |
| `schema_version` | integer | Exactly `1`. |
| `design` | string | Request design stem. |
| `analysis_path` | string | Request analysis semantic path. |
| `analysis_kind` | string enum | `dc_operating_point`, `ac_linear_sweep`, or `transient`. |
| `status` | string enum | `completed`, `failed`, `unsupported`, or `unevaluated`. |
| `request_sha256` | string | Digest of exact canonical request bytes. |
| `map_sha256` | string | Digest of exact canonical map bytes. |
| `axis` | object | Exact axis object below. |
| `signals` | array | Canonically ordered result signals below. |
| `diagnostics` | object array | Normalized diagnostics, strictly sorted and unique by `(code, message)`, never raw stderr. |

## Axis object

| Field | Type | Contract |
| --- | --- | --- |
| `kind` | string enum | `scalar`, `frequency_hertz`, or `time_seconds`. |
| `samples` | string array | Canonical finite numbers in strictly increasing order for frequency/time. |

DC operating point requires `scalar` with exactly one canonical zero. Linear
AC requires `frequency_hertz`. Transient requires `time_seconds`.

## Signal object

Each signal has exactly:

| Field | Type | Contract |
| --- | --- | --- |
| `kind` | string enum | `net_voltage`, `net_voltage_magnitude`, `net_voltage_phase_degrees`, `branch_current`, `branch_current_magnitude`, or `branch_current_phase_degrees`. |
| `canonical_identity` | string | Canonical Design IR net token for voltage signals or component semantic path for branch signals, obtained through the map. |
| `unit` | string enum | `volt`, `ampere`, or `degree`, matching the signal kind. |
| `values` | string array | One canonical finite value for every axis sample. |

Signals are strictly sorted and unique by `(kind, canonical_identity)`.
Binding validation requires each voltage identity to exist in the map's net
namespace and each branch-current identity to exist in its device namespace.

Each diagnostic object has exactly `code` and `message`. `code` is a non-empty
uppercase machine code with hyphen-separated parts. `message` is a non-empty
single-line string without control characters.

## Status invariants

A `completed` result has at least one sample and signal and has no diagnostics.
A completed result bound to a request must contain every requested assertion
signal and exact sample; missing coverage is a binding failure.
A non-completed result has no samples or signals and has at least one normalized
diagnostic. Partial solver output is never normalized as an accepted result.

## Failure behavior

Stale digests, malformed or duplicate CSV structures, non-finite numbers,
wrong axes or units, missing or unknown mappings, inconsistent sample lengths,
or partial results fail with `CC-SIM-CONTRACT-*` or the owning execution
diagnostic. Successful solver exit status alone cannot create `completed`.
